### Машина: ноутбук на `Intel Core i5-10210U` (4 ядра / 8 потоков), 16 ГБ RAM, CachyOS, модель `Qwen3-0.6B`.
### Окружение: Python 3.12, torch 2.14.0+cu130, transformers 5.16.1.

## Замер

Веса на момент замеров уже лежали в кэше HuggingFace, `load_time_sec` — время инициализации модели, без скачивания.

#### Основной прогон, bfloat16

```json
{
  "model": "Qwen/Qwen3-0.6B",
  "device": "cpu",
  "dtype": "bfloat16",
  "load_time_sec": 0.0,
  "tokens_per_sec": 9.87,
  "tokens_per_sec_all": [9.87, 9.82, 9.88],
  "peak_rss_mb": 2272.3
}
```

Повторные запуски демонстрируют высокую стабильность результатов: разброс скорости генерации минимален (9.82–9.88 tokens/sec), порядок величины устойчив.

#### Анализ
`load_time_sec = 0.0` (значение округлено скриптом до сотых долей секунды или загрузка произошла мгновенно из дискового кэша ОС) — время инициализации модели, меряется отдельным таймером вокруг `load_model()` и в скорость генерации не попадает.

`tokens_per_sec = 9.87` (разброс 9.82–9.88 по трём прогонам после прогрева). Взята медиана, устойчивая к случайным системным выбросам. Первый прогон в статистику не входит, так как оплачивает прогрев и инициализацию буферов.

`peak_rss_mb = 2272.3` — максимум за жизнь процесса через `resource.getrusage(RUSAGE_SELF).ru_maxrss`. Укладывается в 16 ГБ RAM с большим запасом, своп не задействован.

**Про dtype.** Формат `bfloat16` оптимален для авторегрессионного декодирования с батчем 1: вычисления упираются в пропускную способность памяти (на каждый токен читаются все веса модели). Уменьшение ширины весов вдвое снижает этот трафик, обеспечивая эффективную работу на процессоре.

## Дефекты и их фиксы

#### 1 Дефект: имя модели захардкожено

Строка с именем модели была прописана прямо в коде вместо чтения из `params.yaml` (в `src/model.py`, `src/generate.py` и `src/bench.py`).
*Исправление:* Заменено на динамическое чтение через `params["model"]["name"]` во всех трех точках.

#### 2 Дефект: зависимости без версий

В `pyproject.toml` зависимости были перечислены без указания диапазонов версий.
*Исправление:* Прописаны безопасные диапазоны с ограничением мажорной версии для ключевых пакетов (`torch`, `transformers`, `accelerate` и др.) для обеспечения воспроизводимости окружения.

#### 3 Дефект: замер скорости включал загрузку модели

В `src/bench.py` таймер стартовал перед `load_model(...)`, из-за чего время загрузки весов искажало показатель `tokens/sec`.
*Исправление:* Таймер загрузки вынесен отдельно (`load_time`), а для замеров скорости генерации запущен независимый цикл с отдельным таймером на каждой итерации.

#### 4 Дефект: генерация не воспроизводилась

Параметр `temperature` был ненулевым, из-за чего включался сэмплинг, а `seed` не фиксировался в коде скриптов генерации и бенчмарка.
*Исправление:* Установлена `temperature: 0.0` в конфиге, а также интегрирован вызов функции `set_seed(seed)` с чтением сида из `params.yaml`.
